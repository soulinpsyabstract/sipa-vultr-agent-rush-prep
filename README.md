# sipa-vultr-agent-rush-prep

**Vultr: Agent Rush Hackathon entry — prep stage.**

Built for [Vultr: Agent Rush](https://lablab.ai/ai-hackathons/vultr-hackathon)
— a hybrid hackathon with an online build phase and a live on-site day for
approved participants (travel/accommodation not covered).

## Status: nothing built yet, on purpose

The hackathon's own page still says most competition specifics are **TBA**:
no prize pool, no track/challenge breakdown, no team size limit, no
submission rules published yet. Building against requirements that haven't
been announced would be guessing, not building — every other SIPA OS
hackathon entry (sipa-trace, sipa-signal, sipa-gpu-guard, sipa-voice-gate)
started from a real, published anchor requirement first.

Confirmed live, even though the rest of the schedule isn't:
- **Online build: 2026-11-03 to 2026-11-08**
- **On-site phase: 2026-11-08** (selected participants only, travel/accommodation not covered)
- Theme (the one thing published): **"Build AI agents that do real work — safely sandboxed on Vultr."** Vultr infrastructure is the mandatory anchor.

## Before it's real

- Watch for the actual prize pool / track / submission-rules announcement
- Once published: pick an angle from the existing SIPA OS toolkit
  (sipa-trace, sipa-signal, sipa-gpu-guard, sipa-voice-gate) rather than
  starting from zero — the Vultr-sandboxing angle likely pairs well with
  sipa-gpu-guard's usage/budget/gate pattern, adapted to Vultr's API
  instead of AMD ROCm
